The documents

The brief pack this site was built from, captured verbatim under briefs/ and readable here. Each page carries the same apparatus — a summary, the key concepts linked to where they landed on the site, the key ideas — and then the full document rendered in-page. The raw file stays the source of truth; the page is presentation. That split is the provenance discipline this site argues for, applied to itself.

Why publish the brief at all. A reader who wants to check whether this site is faithful to what it was asked to build should not have to reconstruct the brief from the site. Publishing the commission makes the site checkable against something other than its own claims — which is the same argument the reality-document rule makes, pointed at this site.

One document from the pack is not published

The source manifest is held back, deliberately. The pack's ninth file is an inventory of source material with repository paths, including the paths of the material it classifies as do-not-publish: investor material, payment and commercial briefs, and a review naming a private individual. Publishing an index to withheld material is a weaker version of publishing the material, so the manifest stays out. The boundaries it defines are restated in full — the decisions are public, the paths are not.

For agents

Every source document is fetchable as raw markdown at a constructed URL under /briefs/. That is a promise rather than an accident: the agent-access report found that agents already rely on constructed paths, so the convention is stated rather than left to be inferred. The whole site is also available as a single file at /llms-full.txt, and the agent surface itself is /llms.txt.
