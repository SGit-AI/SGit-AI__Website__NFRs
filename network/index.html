The network

This site is one of a network of publishing sites under sgit.ai, each owning a domain and linking rather than duplicating. The topic map is the version of this page organised by topic; this one is organised by site, which is what you want when you already know where you are going.

Why both pages exist. An agent looking for a subject needs the topic map. A reader who has landed here from one sibling and wants to know what else there is needs this. Two indexes over the same set is a duplication risk, so the split is explicit: the topic map carries the positions and this page carries only ownership. If you find a position stated here, it is a bug.

What being the hub costs

Every entry above is a link this site depends on and does not control. That is the drift risk stated on the topic map, and it is the reason for the rule the pipeline enforces: link the measurement, never restate it. A broken link on this page is a maintenance problem. A silently wrong restatement would be a false memory, which is a much worse failure and a much quieter one.
